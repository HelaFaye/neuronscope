Godot client

All of Studio as a native app, with its own 3D view of activations: orbit, pan, zoom and preset views from a Blender-style gizmo, the emotion graph and jewel, and a search line, all fixed to the screen however you move. It runs best on a different computer from the one with the models, so drawing never takes GPU memory from them.

On this computer

1. Get Godot 2. Open the client

Get Godot downloads Godot 4 from the Godot project's releases and checks it against their SHA-512 list. Or run ./neuronscope godot.

On another computer

Download the client (.zip)

Unzip it, install Godot 4, and run godot --path neuronscope-godot. Under Connect, enter this Studio's address; on another computer, pair it with a link from Connect → Devices instead of copying the owner token.
